# BARBER 99

Gotowa strona w HTML/CSS/JavaScript. Cała zawartość `dist` nadaje się do wgrania do katalogu głównego repozytorium GitHub Pages. Zachowaj folder `assets`. Otwórz `index.html`, aby uruchomić stronę lokalnie; instalacja nie jest potrzebna.

Fikcyjna marka i przykładowa oferta. Planer nie rezerwuje terminów, nie wysyła danych i nie wymaga danych osobowych. Galeria ma filtry i powiększenie zdjęć, menu działa na telefonie. Animacje respektują ograniczenie ruchu w systemie.
